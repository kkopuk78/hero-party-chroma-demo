# Heroless Party · Web Demo

[Play in your browser](https://kkopuk78.github.io/hero-party-chroma-demo/)

The prophesied hero is missing. As the guild's tactician, guide four companions who fight on their own. Set a party-wide stance, mark a focus target, and place a rally point. Their flaws sometimes lead to unexpected choices.

This is a work-in-progress web demo for the Chroma Awards 2027. It uses rule-based companion behavior. The planned optional local model for the future Steam release is not part of this browser version.

| Control | Action |
| --- | --- |
| Click a route card | Choose the next path |
| 1 / 2 / 3 | Guard / Balance / Assault |
| Click an enemy | Mark focus target |
| Click empty battlefield | Move rally point |
| Hold Space | Slow time while the meter lasts |
| F1 | English / Korean |
| M | Sound on / off |

Built with Godot 4.7.2. Korean text uses Noto Sans KR under the SIL Open Font License 1.1. Art was created with AI image tools for this prototype; audio was synthesized specifically for this game. Source code and design documents are kept in a separate private repository.
